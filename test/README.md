# Unit Tests
Due to the fact that this project is mostly a graphcial interface, few parts of the project are unit testable. However, those which are easily unit testable have test files here. 
<br>
All test files and modules should be named `test_filename.py` or `test_modulename` where filename is the name of the file or class being tested and modulename is the name of the module being tested.
<br>
To run the tests execute the command `python -m unittest discover` from the top level of this project. For this command to work all modules must contain an `__init__.py` file and must follow the above naming convention.
