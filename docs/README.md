# Documentation
this directory contains all files relevant to project documentation. This includes class diagrams, autogenerated Sphinx docs etc. All relevant documentation is on the top level of this directory, with the resources used to generate this documentation being in the sub-directories contained here.

## Generating Docs
To update the documentation, from this directory run `source gen_docs.sh`. This is a simple script to generate all documentation in a viewable format on the top level of this directory.

## Profiler Documentation
This file contains documentation about the built-in GAP profiling package's output format. While this project is not responsible for this output format, no other such documentation existed when this project began, and having it here is useful for development.
To edit this documentation, edit the `profiler_docs/profiler_docs.md` file.

## Class Diagram
this directory contains a UML class diagram written in PlantUML called `class_diagram.puml`. Each time anything in this project is structurally modified, the UML diagram should be updated accordingly.
To edit this documentation, edit the `diagrams/class_diagram.puml` file.
Make sure plantuml is installed before running `source gen_examples.sh` or manually generating the UML class diagram.

## GUI User Guide
The file `user_guide.pdf` contains a step-by-step walkthrough of how to use some of the profiler functionality. This file should be modified whenever the interface is.
To edit this documentation, edit the `user_guide/user_guide.md` file.

## Generating Sphinx Documentation
Each time the docstrings in the code are changed, the Sphinx documentation for the project must be regenerated. This will be done automatically when `source gen_docs.sh` is executed.

If you encounter any issues, make sure the `docs/sphinx_docs/source/conf.py` file contains the following lines:

```python
extensions = [
    'sphinx.ext.autodoc',
    'sphinx.ext.napoleon'
]
napoleon_google_docstring = True
```
Note: as long as the doc strings in each python file are maintained, the Sphinx docs will update every time `source gen_docs.sh` is run.
